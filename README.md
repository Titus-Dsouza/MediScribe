# MediScribe 🩺

MediScribe is an AI-powered clinical documentation assistant that helps users organise their symptoms, medications, and medical history into structured summaries for healthcare professionals.



## ✨ Features

- Patient symptom and medical history intake.
- AI-powered organisation of clinical information.
- Structured summaries for doctor review.
- Review and download clinical reports.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Django
- **AI:** Google Gemini
- **Deployment:** Vercel
- **Version Control:** Git & GitHub



## ⚠️ Disclaimer

MediScribe is designed to support medical documentation, not diagnose medical conditions or replace professional medical advice. All generated summaries should be reviewed by a qualified healthcare professional.
