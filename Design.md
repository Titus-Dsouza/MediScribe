# MediScribe — Design System

## 1. Design Vision

Create a modern, clean and professional medical interface using **glassmorphism throughout the application**.

The experience should feel:
- Clean and minimal.
- Medical and trustworthy.
- Calm and welcoming.
- Easy to understand.
- Comfortable for users of all age groups.

**Design principle:** Keep the interface simple. Make important information easy to see and actions easy to understand.

---

## 2. Visual Theme

### Theme
- Light medical theme.
- Soft blue and white backgrounds.
- Translucent glass surfaces.
- Subtle gradients and shadows.
- Rounded corners.
- Minimal decorative elements.

---

## 3. Glassmorphism Design

Glassmorphism must be used consistently across the application.

### Glass Elements
- Navigation bar.
- Main content containers.
- Questionnaire cards.
- Input fields.
- Buttons.
- Progress indicators.
- Report containers.
- Modal dialogs.
- Dropdown menus.

### Glass Styling
- Translucent white backgrounds.
- Background blur effects.
- Subtle white borders.
- Soft shadows.
- Rounded corners.
- Layered depth.

Avoid excessive transparency that makes text difficult to read.

---

## 4. Typography

Use a modern, highly readable sans-serif font.

**Preferred font:** Inter

### Font Sizes

| Element | Size |
|---|---|
| Main Heading | 36–42px |
| Section Heading | 28–32px |
| Question Heading | 26–30px |
| Body Text | 18–20px |
| Input Text | 18px |
| Button Text | 17–18px |
| Supporting Text | 15–16px |

### Typography Rules
- Use large, readable text.
- Maintain clear visual hierarchy.
- Avoid tiny labels.
- Use medium or semibold font weights for headings.
- Keep paragraphs short.
- Maintain comfortable line spacing.

---

## 5. Application Layout

### Navigation
- Minimal top navigation.
- MediScribe logo and name.
- Simple navigation links where necessary.
- Translucent glass background.
- Clear active states.

### Main Content
- Centered layout.
- Comfortable maximum width.
- Generous spacing.
- Consistent alignment.
- Glass containers with rounded corners.

### Footer
- Minimal footer.
- Short medical disclaimer.
- Copyright information.

---

## 6. Landing Page

The landing page should immediately communicate the purpose of MediScribe.

### Elements
- MediScribe logo.
- Main heading: "Simplifying Clinical Documentation"
- Supporting text: "Share your symptoms. Create a structured clinical report."
- Primary button: "Get Started"
- Minimal medical-themed decorative elements.

### Design
- Large and readable heading.
- Soft blue gradient background.
- Central glassmorphism container.
- Minimal visual distractions.
- Clear call to action.

---

## 7. Patient Questionnaire

The questionnaire is the most important part of the application.

### Layout
- One question displayed at a time.
- Large question heading.
- Clear input field.
- Previous and Continue buttons.
- Visible progress indicator.
- Centered glassmorphism card.

### Question Design
- Keep questions short and simple.
- Use everyday language.
- Avoid complicated medical terminology.
- Provide examples when necessary.
- Clearly identify optional questions.

### Input Fields
- Large input areas.
- Rounded corners.
- Translucent glass styling.
- Clear placeholder text.
- Visible focus states.
- Comfortable spacing.

### Navigation
- Previous button.
- Continue button.
- Progress indicator.
- Smooth transitions between questions.

---

## 8. Report Generation Screen

After questionnaire completion, display a simple loading screen.

### Elements
- Animated loading indicator.
- Heading: "Preparing Your Report"
- Supporting text: "Please wait while your information is organized."

### Design
- Centered glass card.
- Soft blue background.
- Subtle animation.
- No unnecessary information.

---

## 9. Clinical Report Screen

The report screen should prioritize readability over decoration.

### Layout
- Report heading.
- Patient information.
- Clearly separated report sections.
- Edit report button.
- Download PDF button.

### Report Sections
- Patient Information.
- Chief Complaint.
- History of Present Illness.
- Symptoms.
- Medical History.
- Medications.
- Allergies.
- Clinical Summary.
- Professional Review Notes.

### Design Rules
- Use clear section headings.
- Maintain large readable text.
- Use subtle glass containers.
- Avoid excessive colors.
- Keep report content structured.
- Make editing straightforward.

---

## 10. Buttons and Interactions

### Primary Button
- Blue background.
- White text.
- Rounded corners.
- Large clickable area.
- Subtle hover animation.

### Secondary Button
- Translucent glass background.
- Blue text.
- Soft border.

### Interaction Rules
- Smooth transitions.
- Clear hover states.
- Visible focus indicators.
- Disabled states for unavailable actions.
- Loading states during processing.
- Clear success and error feedback.

---

## 11. Icons and Decorative Elements

- Use simple medical-themed outline icons.
- Prefer consistent icon styling.
- Use icons only when they improve understanding.
- Avoid unnecessary illustrations.
- Avoid cluttered backgrounds.

Suggested icons:
- Medical cross.
- Heartbeat.
- Clipboard.
- Stethoscope.
- Document.
- Shield.
- User.

---

## 12. Responsive Design

The application must work across:

- Desktop.
- Laptop.
- Tablet.
- Mobile.

### Mobile Requirements
- Full-width questionnaire cards.
- Large touch-friendly buttons.
- Readable text without zooming.
- Proper spacing.
- No horizontal scrolling.
- Responsive navigation.
- Properly formatted reports.

---

## 13. Accessibility

- Maintain strong text contrast.
- Use readable font sizes.
- Provide visible input labels.
- Ensure keyboard navigation.
- Use clear error messages.
- Do not rely on color alone to communicate status.
- Maintain accessible button sizes.

---

## 14. Final Design Rules

1. Use glassmorphism consistently throughout the application.
2. Maintain a light medical-themed appearance.
3. Keep the interface minimal and uncluttered.
4. Use large, readable typography.
5. Keep all text short and to the point.
6. Prioritize usability over decoration.
7. Maintain consistent spacing and rounded corners.
8. Use subtle animations only.
9. Ensure accessibility and mobile responsiveness.
10. Keep the clinical report professional and easy to read.

**Final Goal:** A minimal, elegant and trustworthy medical interface that makes completing questionnaires and reviewing clinical reports effortless.
